# Arafat Rahaman — Chemical Engineering Portfolio Website

This archive contains your complete personal portfolio website in two convenient formats:

1. **`index.html` + `assets/` folder (Recommended for Web Hosting)**
   - Lightweight HTML file linked to external high-resolution images in `assets/`.
   - Ready to upload directly to **GitHub Pages**, **Netlify**, **Vercel**, or any static web host.

2. **`arafat_rahaman_portfolio.html` (Standalone Single-File Version)**
   - Self-contained HTML file with all images embedded inline.
   - Can be shared as a single file via email or opened offline in any browser.

## Quick Deployment (GitHub Pages / Netlify Drop)
- **Netlify Drop (Fastest, 30 seconds):** Go to https://app.netlify.com/drop and drag-and-drop the unzipped folder.
- **GitHub Pages:** Create a new repository on GitHub, upload `index.html` and the `assets/` folder, and enable **Settings -> Pages -> Deploy from branch (`main`)**.
